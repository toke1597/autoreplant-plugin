# AutoReplant

다 자란 작물(밀, 당근, 감자, 비트, 횃불꽃, 네더 사마귀)을 캐면 인벤토리의 씨앗을 하나 써서 자동으로 다시 심어주는 Paper 플러그인.
인벤토리에 씨앗이 없으면 방금 떨어진 드롭에서 하나 가져옵니다. 크리에이티브 모드에서는 씨앗을 쓰지 않습니다.

Fabric 모드 Auto Replant 를 Paper(26.3) 플러그인으로 옮긴 것입니다.

- 권한: `autoreplant.use` (기본: 모두)
- 빌드: `./gradlew build` → `build/libs/AutoReplant-1.0.0.jar`
